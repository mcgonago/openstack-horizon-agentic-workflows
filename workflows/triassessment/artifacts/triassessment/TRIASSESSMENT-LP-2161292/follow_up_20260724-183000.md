### What the Fix Does

**Problem Addressed:**  
When Horizon passes credentials with `domain_id` present to oslo.policy, oslo.policy assumes the token is domain-scoped. This causes all project-scoped policy checks to fail, resulting in missing buttons and actions throughout the Horizon UI.

**Solution:**  
- **Conditionally pass `domain_id`**: Only include `domain_id` in credentials when the policy check is explicitly scoped to the domain
- **Default behavior**: For project-scoped checks, omit `domain_id` from credentials so oslo.policy correctly infers project scope

**Technical Approach:**  
Modified the credential-building logic to detect the intended scope (project vs domain) and only pass `domain_id` when domain scope is required. This aligns with oslo.policy 6.0.0's stricter scope enforcement while preserving Horizon's existing policy check behavior.
